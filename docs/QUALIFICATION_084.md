# 0.8.4 contextual course qualification
Thirty original contextual packages: days 2–4 of each of the ten months, with separately preserved legacy course progress. Each includes six lexical entries (five across the bank reuse existing IDs), five bilingual phrases, one original reading with three comprehension questions, one three-exercise grammar micro-lesson, one four-turn bilingual dialogue, five speaking prompts, three writing choices, a model writing response and three transfer questions. Total: 175 newly counted lexical units, 150 phrases, 30 texts, 90 grammar practice tasks, 90 transfer checks (30 typed grammar tasks), 150 speaking prompts, 90 writing prompts, 30 dialogue scripts, 30 listening questions. The base 300-day route is retained; new routes are selectable within mapped days and do not mark legacy completion or CEFR mastery. Suggested study modes are not timers or proof of time spent.
Audio is generated locally during CI with eSpeak and FFmpeg, two synthetic voice variants, level-based rate, native HTML audio player, independent decode and hash manifest. It is not human-recorded speech. Playback event is not evidence that a user heard audio. Transcript use marks assisted practice. No paid services enabled.
Technical language examples are fictional documentation discussions, not operating instructions. Terminology references: IEC TR 61850-90-11:2020 https://webstore.iec.ch/en/publication/32080 (Logical Node and Data Object names); NIST metrological traceability https://www.nist.gov/metrology/metrological-traceability (calibration evidence and uncertainty). These are reference checks, not independent review of translations.
